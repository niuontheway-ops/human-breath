    🌿 关于「壶兰呼吸」

    「壶兰」取自莆田壶公山与木兰溪。LOGO 以壶公山叠翠、木兰溪蜿蜒为意象，山溪交织，如呼吸之吐纳往复。本应用面向慢阻肺、哮喘、支气管扩张等慢性气道疾病及胸腹部术后患者，提供语音与动画引导式呼吸康复训练，帮助改善肺功能、缓解呼吸困难。

    📖 使用说明

    • 每日 2–3 次，每次 10–15 分钟，循序渐进；
    • 训练时保持肩颈放松，深吸慢呼，跟随语音引导；
    • 完成训练后自动打卡，并生成统计图表与评估趋势；
    • 首页「老年模式」可一键放大全站字体；
    • 首页左上角 ☰「音乐疗法」可选舒缓音乐，训练时自动播放，每组之间自动休息 2 秒。
    • 交互设计参考 GitHub 开源呼吸训练项目（Breathly、ZenFlow、Calmness 等）。

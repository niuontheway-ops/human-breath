🌿 关于「壶兰呼吸」

「壶兰」取自莆田壶公山与木兰溪。山溪交织，如呼吸之吐纳往复。本应用面向慢阻肺、哮喘、胸腹部术后等患者，提供动画引导式呼吸康复训练，帮助改善肺功能、缓解呼吸困难。

📖 使用说明

  • 每日 2–3 次，每次 10–15 分钟，循序渐进；
  • 训练时保持肩颈放松，深吸慢呼；
  • 完成训练后自动打卡记录；
  • 交互设计参考 GitHub 开源呼吸训练项目（Breathly、ZenFlow、Calmness 等）。
